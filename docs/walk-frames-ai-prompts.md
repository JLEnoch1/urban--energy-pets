## 1. 引擎 N 帧行为(brief「路径 B」已实现,不用加 `stepFrames`)

`gaitTransform` 已按帧数 `n` 泛化:`ph = (idx+φ)·2π/n` ——

- **颠簸频率锁定为每循环 2 次**(对角/交替负重各一次),与帧数无关:4 帧素材放进自动「每两帧一起伏」,
  波谷恰落在 F1/F3 负重帧、波峰在 F2/F4 过渡帧。`n=2` 时公式退化为旧版 `(idx+φ)·π`,行为不变。
- brief 的 `stepFrames: 2` 与此等价(`π/stepFrames ≡ 2π/n`,n=2·stepFrames);
  skin.json 里若照抄 brief 带上 `"stepFrames"` 键,会被引擎**无害忽略**,可留可删。
- `interval` = **每次帧前进**的时长:4 帧要保持现步频用 `[0.07,0.11]`;想慢踱步用 `[0.14,0.22]`。
- `crossfade` = 每帧末段把下一帧淡入的占比:4 帧帧差小,**0.3–0.4** 更稳(两帧时代是 0.3)。
- **幅度分工(重要)**:brief 要求 F2/F4 把「身体最高点」**画进帧里** —— 那么程序化颠簸只补残余,
  `bobAmp` 降到 **1–1.5**、`squashAmp ≤0.006`、`swayAmp ≤0.01`,否则帧内起伏+程序起伏=双倍颠簸。
  若生成帧是等高的(起伏全靠引擎),则保持 `bobAmp: 3` 一档。
- 顶边踱步(`perch`/walk 子模式)已映射到同一套 walk 帧与步态引擎,补帧后顶边散步同步变平滑。
- 速度同步不变:步频按 `refSpeed/实际移速` 缩放(钳制 0.6–1.8),地面 46px/s、顶边 40px/s。

## 2. 硬规格速查(与 brief §6 一致,附管线行为注释)

| 项 | 规格 | 管线原因(`main.js`) |
| --- | --- | --- |
| 画布 | 正方形 1280×1280(≥720 即可) | `matteImage` 长边 >720 统一降采样 |
| 背景 | 纯白 `#FFFFFF`,无渐变/暗角/**地面阴影** | 漫水只删「亮度≥190 且近中性(max−min≤14)」且与四边连通的区域;阴影渐变留灰边(渲染器自己画椭圆阴影) |
| 留白 | 主体不触边,四周 ≥10% | 漫水从画布四边出发,触边会剩白斑 |
| 描边 | 暖棕描边**闭合连续** | 近白毛发(胸口/腹/爪内)全靠描边挡住漫水,断线=身体被咬洞 |
| 游离物 | 无装饰、无游离色点、无反射 | 任何非白残留都撑大裁切包围盒 → 帧间漂移 |
| 基线 | 四帧同比例、同地平线、同居中;**最低点=脚掌,尾不低于地平线** | 抠图后按 alpha 包围盒裁切、以「底边中心」锚到 GROUND |
| 位移 | 原地走,主体零水平位移 | 位移由窗口移动实现;主体在画布里平移 → 裁切后左右抖 |
| 透明 PNG | 直接放入也安全 | 漫水对已透明像素不生效,alpha 原样保留 |
| 命名/热重载 | `walkcycle.jpg`(宫格)或 `walkF1..F4.jpg`;丢进 `skins/default/` 即自动抠图+热重载 | `watchSkins` 目录监听;也可右键猫 →「重新加载皮肤」 |

## 3. 验收工具:`scripts/walk-preview.html`

浏览器直接打开(`open scripts/walk-preview.html`),零依赖:

- **复刻管线**:选入 JPG/PNG 后自动执行与运行时相同的「≤720 降采样 → 漫水抠图 → 包围盒裁切」,
  所见即所得;背景可切**深色**检查白块残留/灰边/描边被吃。
- **同公式动画**:与 `sprite-skin.js` 完全一致的步态数学(交叉溶解/步相位/移速同步/颠簸摇摆压扁/起步渐入),
  滑杆调参实时生效,HUD 显示 φ、lift、bob、溶解层数;跑步机参考线直观检查「步频 vs 移速」是否打滑。
- **比例参考**:务必选 `idle` 作为比例参考图 —— 运行时 `scale=250/idle高`,不选会用第一帧归一化,
  **掩盖帧间大小差**(比如误把小尺寸 cell 当合格素材)。
- **帧序管理**:↑↓ 调序验证「负重帧波谷对齐」;✕ 删帧。
- **一键导出**:镜像 PNG(walk*m)、白底合成 PNG(图生视频首帧料)、skin.json `anim` 片段。

## 4. 备选路线 S:侧面循环(步态更真实,但换了朝向)

侧面行走符合横向位移的物理直觉,但**现有 idle/sleep/pet/tap 全是正面**:只把 walk 换成侧面,
状态切换(0.12s 溶解)会出现「正面↔侧面」的朝向跳变,溶解遮不住。除非愿意把 idle 也换成侧面,
否则不建议;真要换,按下面两条走:

1. **零 AI 应急**:sheet `88e22dcf…jpg` 的 cell 2/3/4 是现成侧面走 3 连帧(`walkSide` 状态已配置)。
   ⚠️ 两个坑:① cell 只有 ~139px 高,运行时按 `250/idle高(572)` 缩放后会**缩成 ~61px 的迷你猫**,
   必须先把 cell 放大到 ~570px 高再用(如 `sips -z 570 1128 in.png --out out.png`,4 倍放大会发糊,仅应急);
   ② 奇数 3 帧时颠簸相位与帧略偏(幅度 ≈0.87、差 ¼ 帧),可用不工整。
2. **AI 重生成侧面 4/8 帧**(推荐做法):用 brief 的角色卡改成「side view facing right」,
   加提示词「quadruped walk cycle, diagonal leg pairs alternating, contact pose / passing pose」,
   2×2 宫格一次生成(规格同 §2,朝向改为侧面朝右;向左走由 `pose.face=-1` 镜像,只需一套)。
   也可图生视频抽帧:首帧 = 侧面参考图合成白底(预览工具可导出),
   视频提示词「小猫侧面原地行走,对角腿交替,镜头固定,纯白背景,主体居中不位移」,2–3s,
   `ffmpeg -i walk.mp4 -vf "select='not(mod(n\,8))'" -vsync vfr f%02d.png` 抽帧后挑
   「四肢最收拢、身体最高」的过渡帧与「四肢张开最大、身体最低」的着地帧。

## 5. 备选路线 Q:正面 4 拍的「1 帧 AI + 镜像」快捷道(有代价)

只想最低成本先上线:F2 由 AI 生成(过渡帧,brief §4 Pose 2),然后

```bash
# macOS 自带 sips(已验证);或 ImageMagick: magick in.jpg -flop out.jpg
sips --flip horizontal skins/default/walk1.jpg  --out skins/default/walkF3.jpg
sips --flip horizontal skins/default/walkF2.jpg --out skins/default/walkF4.jpg
```

帧序 `[walk1, walkF2, walkF3, walkF4]`。**代价**:镜像会连斑纹/光影一起翻转 ——
brief §4 F3 明确要求「斑纹保持同一只猫的连续性(不要镜像)」,所以这是「先上线后优化」档;
小尺寸 + 每帧 ~0.09s + 交叉溶解下,斑纹翻转基本无感。预览工具的「镜像下载」按钮效果相同
(输出抠好的透明 PNG,可直接丢回皮肤目录)。

## 6. skin.json 接入(正面 4 拍 · 宫格方案,对齐 brief §7)

```jsonc
"sheets": {
  "walkcycle.jpg": { "grid": { "cols": 2, "rows": 2 } }   // splitGrid 行优先:0=左上,1=右上,2=左下,3=右下
},
"states": {
  "walk": {
    "sheet": "walkcycle.jpg",
    "cells": [0, 1, 2, 3],
    "anim": {
      "interval": [0.07, 0.11],   // 保持现步频;慢踱步改 [0.14,0.22]
      "refSpeed": 46,
      "bobAmp": 1.2,              // 帧内已画起伏 → 只补残余(帧等高则用 3)
      "swayAmp": 0.008, "swayPhase": 1.57, "squashAmp": 0.006,
      "crossfade": 0.35, "entryT": 0.25, "stateXfade": 0.12
    }
  }
}
```

独立 4 图方案把 `sheet/cells` 换成 `"frames": ["walkF1.jpg","walkF2.jpg","walkF3.jpg","walkF4.jpg"]`。
帧序必须是循环序(负重→过渡→对侧负重→过渡);排错序 = 颠簸与姿态反相(负重的瞬间身体最高),一眼假。
回滚预案:改回 `"frames": ["walk1.jpg","walk2.jpg"]` + 原 anim,热重载即回两帧版。
